# Upload to GitHub

1. Extract the ZIP and open the `modulated-bathymetry-showcase` directory.
2. Create a repository in your own GitHub account, with your preferred visibility.
3. Upload the **contents** of this directory so that `README.md`, `assets/`, and `docs/` are at the repository root. Preserve the subdirectories and filename case.
4. Open the repository home page to view the animated README. Relative links and local assets work without editing a username or repository name.
5. Keep `CITATION.cff` and `LICENSE` at the root. If a permanent repository URL or DOI is later assigned, add verified metadata to the citation file.

No GitHub Pages deployment, JavaScript, secret, API key, build server, or external image host is required. The ZIP is ready to upload; it does not create or publish a repository automatically.

Suggested repository name: `modulated-bathymetry-showcase`.

Suggested description: “Original scientific animations and reproducible linear-wave calculations for transverse dispersion over modulated periodic bathymetry.”

Suggested topics: `shallow-water`, `bathymetry`, `wave-propagation`, `homogenization`, `scientific-visualization`, `dispersion`.
